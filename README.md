# Jonathan — Developer Portfolio

Responsive portfolio built with React, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml` that builds `dist/` and publishes it to GitHub Pages whenever `main` is updated.

In GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.

Update the GitHub and LinkedIn URLs and email address in `src/main.jsx` before publishing.
